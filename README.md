# App Starter

A minimal TypeScript app shell, ready for a new product experience.

## Commands

- `npm run dev` serves the project locally at http://localhost:5173.
- `npm run build` compiles the app into `dist`.
- `npm run preview` serves the production build at http://localhost:4173.

The app starts in `src/main.ts`; global styles live in `src/styles.css`.
